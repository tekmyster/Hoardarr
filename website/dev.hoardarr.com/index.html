A calmer storage workflow

Tell Hoardarr the outcome. It handles the layers.

Standard mode detects what it can, recommends a complete stack, and asks only the questions that materially affect your data.

Detect

Disks, paths, sectors, health, pools, filesystems, shares, LUNs, and existing data.

Understand

Media, downloads, backups, VMs, databases, mixed workloads, or a custom goal.

Recommend

Topology, protection, growth plan, datasets or zvols, tuning, and presentation.

Review

Plain-language consequences, capacity, compatibility, risks, and every proposed action.

Apply

One validated plan using the same backend policies and safety controls as Advanced mode.

One engine · two ways to work

Simple enough to start. Deep enough to stay.

Grandma and an ONTAP developer should be able to configure the same safe storage plan at the level that makes sense to them.

Default

Standard mode

Goal-first guided setup

Hoardarr detects hardware, preselects recommended quick options, and explains the decisions that matter.

  • ARR and media-library presets
  • Recommended layouts from detected disks
  • Quick format and fast validation by default
  • No silent guesses about destructive choices

Advanced mode

The full storage stack, still guarded

Inspect and override the same plan layer by layer without switching to a separate storage engine.

  • Disk and path characteristics
  • Vdev, pool, dataset, zvol, share, and LUN controls
  • Multipath, replication, quorum, and HA visibility
  • Enterprise-grade depth without license gates
