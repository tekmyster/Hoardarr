A product, not a command collection

Every control belongs to a layer.

Physical device → path and partition → redundancy → pool → dataset or zvol → SMB/NFS share or iSCSI LUN → application-visible storage.

Hoardarr exposes a control only when it can detect, explain, validate, execute, and read it back. Advanced mode adds depth, not a bypass around safety.

Product principle

Home lab first. Wizard ease second. Enterprise depth on demand.

No business licensing model. No feature ransom. No requirement that a media enthusiast become a storage engineer before creating a protected pool.
