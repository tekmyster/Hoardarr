First public release

A usable storage server from one ISO.

The Alpha target is deliberately practical: boot, install, discover storage, create or import a pool, expose it to your ARR stack, and understand what the hardware is doing.

First Alpha target

What the image is being prepared to deliver

  • Rufus-ready Ubuntu 24.04 amd64 installation media
  • Guided system-disk selection with strong exclusion from storage pools
  • First-run WebUI and detected hardware inventory
  • Standard and Advanced views of one storage plan
  • ZFS RAIDZ1, RAIDZ2, and RAIDZ3 pool creation
  • Existing ZFS pool discovery, review, and import
  • Permission preservation, identity remapping, or deliberate replacement on import
  • SMB and NFS file shares with users and storage-group access
  • iSCSI targets and LUNs for block-storage clients
  • Quick formatting and bounded fast tests as the recommended defaults
  • Live pool, device, bandwidth, IOPS, and latency telemetry
  • Scrub, degradation, replacement, resilver, export, and recovery workflows
  • Auditable plans and readback around destructive actions
  • Offline-friendly application bundle and future update/rollback path

Honest Alpha boundaries

What “coming soon” means here.

The image will be published when the installer and first-run storage path are repeatable enough for a real homelab—not merely because an ISO file exists.

Validated now

Standalone storage core

Live ZFS creation/import, SMB/NFS/iSCSI I/O, telemetry, degradation, replacement, scrub, and a complete WebUI demo have been exercised.

Release work

Installer and appliance finish

Boot/install continuity, first-run behavior, recovery, image size, release evidence, and USB-media testing are the publication gate.

After Alpha

HA, cluster, and deeper dashboards

Two-node failover, local replication, shared-storage fencing, customizable persistent dashboards, and three-plus-node cluster mode remain active development.
