# Hoardarr requirements traceability

This matrix tracks the product specification supplied for the 0.3.9 Beta 1
review against the repository now reporting 0.3.11 Beta 1. `Current`
describes evidence available at baseline. `Final` is updated only from executed
validation; it uses the required status vocabulary.

Evidence abbreviations: `BT` = backend tests, `FT` = frontend tests, `IT` =
isolated execution test, `HP` = matching physical hardware. An absent `HP`
never implies hardware certification.
